# COVID-19 Global Trends & Analysis Dashboard

## Project Overview
The COVID-19 Global Trends & Analysis Dashboard is an interactive data analytics project developed using Microsoft Power BI. It explores reported COVID-19 cases and deaths across countries and over time, helping users understand trends and compare country-level statistics.

## Objectives
- Analyze COVID-19 case and death trends over time.
- Compare reported cases across countries.
- Present key metrics through interactive KPI cards.
- Enable filtering by country and date range.
- Practice data cleaning, transformation, and visualization.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data transformation
- DAX for calculated measures
- CSV dataset from Our World in Data

## Dashboard Features
- Total COVID-19 Cases KPI
- Total COVID-19 Deaths KPI
- COVID-19 Death Rate KPI
- New Cases Trend Over Time
- New Deaths Trend Over Time
- Top 10 Countries by Reported COVID-19 Cases
- Interactive country and date range slicers

## Data Source
Our World in Data — COVID-19 dataset  
https://ourworldindata.org/coronavirus

## Project Workflow
1. Downloaded the COVID-19 dataset.
2. Transformed the data and removed unnecessary columns.
3. Removed duplicate records and rows with missing country or date values.
4. Created DAX measures for key indicators.
5. Designed interactive visuals and slicers in Power BI.
6. Organized and formatted the dashboard.

## Key Learning Outcomes
- Data cleaning and transformation
- Data modeling and DAX calculations
- KPI development
- Time-series and country-level analysis
- Interactive dashboard design

## Important Note
Reported totals depend on the dataset's reporting coverage and date range. Missing data, reporting revisions, and differences in country reporting practices may affect comparisons. Calculated metrics should be validated against the source data before drawing conclusions.
